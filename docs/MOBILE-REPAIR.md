# 手機字型與療程卡片修復

日期：2026-10-02

## 使用者回報

iPhone 截圖中，「苦茶籽潔淨髮浴」「墨玉烏」「薑暖陽」出現同一標題字形、粗細不一致的情況，浮動 LINE 提示也遮擋療程內容。上次驗收只確認版面尺寸與溢出，未充分核對手機字型實際呈現。

## 修正

1. **字型隨網站提供**：移除執行時的 Google Fonts CSS／按字元分片請求，改為網站同源的單一繁體中文字型 WOFF2，包含目前所有靜態中文字與標點。保留 Noto Serif TC 的明體外觀，公開頁共用同一份 300–700 可變字重字型；西文裝飾字型也改為同源載入。繁體中文字型約 385 KiB，西文字型約 86 KiB，避免在手機下載完整 16 MiB 原始字型。字型授權及來源保留於 `public/fonts/`。
2. **一致的字重與行高**：療程名稱統一使用字重 500，手機標題 17px；副標 13px，增加行高、縮小過大的字距。停用瀏覽器人工合成字重。首頁棕色標語仍使用字重 700，保留原本 1.6 秒掃光、5 秒停頓及完整細線。
3. **真正的展開按鈕**：卡片原本同時使用滑鼠進入展開和點擊切換，手機的相容滑鼠事件可能造成剛展開又收起。改為原生按鈕，明確點擊／鍵盤切換；滑鼠離開不會收起。收起的內容使用 `hidden`，展開內容不再受固定 680px 高度限制。
4. **手機版卡片尺寸**：移除清單重複的左右內距，縮減區塊之間過大的留白；三組療程使用相同的標題／價格結構、基線和間距。價格從後台取得，沒有改價。
5. **LINE 不遮擋操作**：手機隱藏自動彈出的文字提示並取消大光暈。療程卡片或預約區出現在畫面時，手機浮動 LINE 入口隱藏；療程下方提供固定的 LINE 咨詢連結。其他區域保留原有圓形入口，位置加入安全區間距。
6. **可維護的字型檢查**：新增 WOFF2 雜湊、中文字元涵蓋、字重及預載入檢查。將來新增靜態中文字但未更新字型時，檢查會指出缺字，避免再次無聲回退。

## 主要檔案

| 檔案 | 修改 |
| --- | --- |
| `src/App.jsx` | 原生卡片展開按鈕、排版、字重、LINE 顯示規則、療程諮詢入口 |
| `src/public-theme.css` | 同源字型、字型回退、價格與手機間距、安全區樣式 |
| `index.html` | 預載入單一中文字型；移除外部字型入口；設定 viewport 安全區 |
| `src/Contact.jsx`、`src/Shop.jsx` | 共用公開頁字型 |
| `public/fonts/` | WOFF2、來源、授權、字元涵蓋與雜湊紀錄 |
| `scripts/build-public-fonts.py` | 維護時生成字型子集；正式網站不需要 Python |
| `scripts/test-public-fonts.mjs`、`package.json` | 納入字型回歸檢查 |

## 驗證與限制

- 既有 288 項營運檢查及新增字型檢查通過；正式構建與差異格式檢查通過。
- 已在實際瀏覽器檢查字型載入：公開頁只需要兩個同源字型，涵蓋使用者圈出的療程名稱；阻擋 Google Fonts／gstatic 後仍能正常載入。
- 手機療程畫面逐字核對明體外觀、統一字重、價格基線和間距。
- 中英文首頁分別驗證 320、375、390、430、768、1440px 共 12 組尺寸，沒有水平溢出；兩種語言的 7 張療程卡片都能展開、收起，完整內容未被裁切。
- 聯絡、商品展示、預約查詢、會員與後台登入入口，在兩種語言、4 種手機寬度下共 40 組頁面檢查通過。後台維持繁體中文介面。
- 中英文、320／390px 共 4 次預約流程，完成療程、技師、日期與時段選擇並進入確認頁；沒有送出真實預約。
- 未修改 Supabase 資料、帳號、角色、薪酬、餘額、床位、預約規則或價格。
- 字型子集涵蓋目前程式中的靜態文字；未來新增字元須重新生成。顧客輸入或後台新增的罕見字可能使用本機明體回退。
- 本機驗收使用 Chromium 與手機尺寸／事件模擬，不能等同於實體 iPhone Safari 驗收。截圖所示的字型載入風險已透過同源字型修復；沒有宣稱完成實機 Safari 測試。
