# 服务主疗程与加购项目更新

## 新的目录规则

- 官网上的主疗程只保留 **45、90、120 分钟**三个固定分类。
- 原本属于 60 分钟分类的服务会转为「加购项目」，并默认显示在三个主疗程分类下。
- 后台之后新建的任何服务都会自动建立为加购项目，不能误建成新的主疗程分类。
- 加购项目必须至少选择一个归属的主疗程，可同时选择 45、90、120 分钟多个分类。
- 加购项目不会出现在独立预约清单；在官网疗程页中会显示于所选主疗程底下，并继续提供给 POS 与薪资计算使用。

## 后台操作

1. 进入「服务・商品・库存」→「服务项目」。
2. 点击「新增加购项目」。
3. 输入名称、加购时间、价格、缓冲时间与官网介绍。
4. 在「显示于主疗程」至少勾选一个 45、90 或 120 分钟分类。
5. 设为「上架」并开启「官网显示」后，前台会自动放到相应主疗程底下。

既有 45、90、120 分钟主疗程仍可编辑名称、价格、文案、官网状态和独立预约状态，但不能改成其他时长或加购项目。这样能避免前台分类再次出现不一致。

## 数据保护与联动

- 历史预约继续保留原成交服务、时长与价格快照。
- 原来绑定 60 分钟分类的职称提成规则会迁移到加购分类，避免薪资计算断开。
- 删除未使用的加购项目会永久删除；已有订单、预约或套票记录时沿用安全封存逻辑。
- 后台目录接口会回传每个加购项目的主疗程归属，前台不再根据名称或显示顺序猜测分类。

## 视觉更新

- 后台页面底色改为中度咖啡色，降低原本偏亮的米白背景。
- 卡片、输入框、导航与表格同步采用咖啡、奶茶与铜金色阶，保留现有交互和可读性。
- 官网加购区采用较紧凑的统一卡片，在桌面与手机上都保持与主疗程一致的排版。

## 验证

- 完整自动测试通过：数据库、预约、权限、员工、薪资、目录与字体覆盖。
- 生产构建通过。
- 数据库测试确认：新建服务会被强制设为加购项目、必须选择主疗程、不会成为独立预约服务，并能按选择归属出现在官网。
