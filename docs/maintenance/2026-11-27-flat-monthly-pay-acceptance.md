# 兼職月薪統一與人事排班連動驗收

核對日：2026-11-27。適用類別：02 兼職月薪技師。

## 計薪規則

六個職級（試用、初級、資深初級、中階、資深中階、高階）的本薪統一為 **NT$25,200／月**。職級仍決定普通服務起抽比例，原 0%、5%、10%、15%、20%、25% 與指定客、商品／課程券規則沿用。本薪不因晉級、試用通過或修改排班天數而自動增加。

店主在「薪資與提成 → 制度設定 → 服務時數與起抽」查看 **02 兼職統一月薪（NT$／月）**。只留一個本薪欄位，六階共用；未來調整須依制度版本規則建立草稿。職級表維護抽成，不再有六組本薪輸入。新草稿複製共用本薪；伺服器拒絕六階混用不同本薪。

畫面用新臺幣元，內部保存整數分：25,200 元對應 2,520,000 分。試算、加班時薪基數、來源明細、員工薪資及匯出都取同一筆制度本薪。已結算歷史快照保留原值。

## 修正與連動

| 項目 | 結果 |
| --- | --- |
| 制度設定 | 新增制度共用本薪，現行 v7／v8 已統一 25,200；六階相容資料也同步更新 |
| 計算引擎 | 02 類別以制度共用本薪為準；通過試用或升等不會再從職級帶入較高月薪 |
| 儲存驗證 | 更新共用金額時六階一起儲存；舊頁面混送個別金額會整次拒絕，提示重新整理 |
| 人事分類 | 正職／兼職時薪／兼職月薪／承攬沿用人事資料；兼職月薪轉換與六階同步薪資草稿 |
| 排班提醒 | 優先依明確人事類別，修正尚無生效薪資配置時，月薪技師被誤判成時薪提醒的情況 |
| 班表與官網預約 | 排班開放該技師可約；休班關閉。這些變更不把統一月薪換成時薪或依天數自動扣減 |
| 歷史資料 | 套用前確認現行 notice 制度沒有正式結算引用；若有引用則整批停止，需建立新版本 |
