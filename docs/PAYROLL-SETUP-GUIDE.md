# 柔療髮浴｜薪資與提成設定操作手冊

更新日期：2026-10-04

本手冊說明後台「薪資與提成」每一個欄位的用途、正確單位、建議設定順序，以及它和人事、預約、POS、加班及結算的關係。

## 一、系統的計薪邏輯

薪資制度現在以兩個條件共同決定：

> 按摩師職稱 × 聘僱類型

例如「資深調理師 × 全職」共用一套薪資，「資深調理師 × 兼職」可使用另一套。人事頁只指定員工的職稱與聘僱類型，不再為每個人重複輸入基本薪酬和提成。

1. 同職稱、同聘僱類型的人使用相同制度。
2. 修改一套制度後，所有符合條件的在職人員會一起套用。
3. 已鎖定的歷史薪資結算保存當時快照，不會被新制度改寫。

## 二、先在人事頁完成的資料

進入「人員與排班」，逐一確認：

| 欄位 | 用途 |
| --- | --- |
| 按摩師職稱 | 決定薪資制度，也會顯示在官網技師選擇中 |
| 聘僱類型 | 與職稱共同決定薪資制度，例如全職、兼職、承攬 |
| 任職狀態 | 在職、已離職或停用；離職人員保留歷史薪資 |
| 可提供療程 | 控制前台可預約服務，也控制 POS 服務可指定的技師 |
| 預約接單／官網顯示 | 控制排班及前台顯示 |

薪資金額、服務提成、商品提成和指定客獎金只在「薪資與提成」設定。

## 三、職稱薪資設定

進入「薪資與提成」，點選「職稱薪資設定」。先選擇一個「職稱 × 聘僱類型」，再編輯以下欄位。

### 3.1 薪酬基準

| 選項 | 基本薪酬欄位代表的內容 | 本薪計算 |
| --- | --- | --- |
| 月薪 | 每月固定薪資 | 所選薪資期間計入基本月薪 |
| 時薪 | 每小時薪資 | 時薪 × 核准工時分鐘 ÷ 60 |
| 每堂薪酬 | 每完成且已結帳一堂的固定薪酬 | 每堂薪酬 × 已結帳服務堂數 |

### 3.2 基本薪酬

- 單位：`NT$ 元`
- 可輸入小數，例如 `190.50`。
- 畫面輸入元，系統自動換算為整數最小貨幣單位保存，避免浮點誤差。
- 月薪例：`36000`；時薪例：`190`；每堂例：`500`。

### 3.3 服務提成

- 單位：百分比 `%`，輸入 `12` 表示 12%。
- 預約完成並結帳後，提成歸目前的實際服務技師。
- 後台更換實際技師時，預約、評價、完成堂數和提成會一起改歸新技師。
- POS 服務在收款時指定實際技師，也使用這個比例。
- 若該「職稱 × 聘僱類型」已設定階梯，本欄是沒有可用階梯時的後備比例。

### 3.4 商品提成

- 單位：百分比 `%`。
- POS 商品若指定銷售人員，商品提成歸該人員。
- 未指定銷售人員時，商品照常成交，但不產生人員商品提成。

### 3.5 指定客獎金

- 單位：百分比 `%`，輸入 `5` 表示該堂有效服務收入的 5%。
- 顧客會員檔案有指定技師，且由該技師實際完成、結帳且未退款時，自動計入。
- 計算式：`指定客加成 = 指定客服務收入 × 職稱指定客比例`。
- 如需一次性修正，可另用「新增加扣項」中的「指定客獎金」。

### 3.6 出勤與服務門檻

| 欄位 | 單位 | 用途 |
| --- | --- | --- |
| 提成資格：最低出勤 | 小時／月 | 兼职等制度先检查当月核准出勤；未达门槛时服务提成为 0 |
| 服务提成起算 | 服务小时／月 | 例如正职输入 `65`，前 65 服务小时由底薪涵盖 |

出勤小时来自“登录出勤”；服务小时来自已完成、已结账、未退款的预约或 POS 服务，两者不会混用。

### 3.7 規則狀態

- 啟用：薪資試算正常套用這套制度。
- 停用：符合這個組合的人不再取得這套基本薪酬和提成。停用前應先確認是否有在職人員使用。

## 四、加班規則版本

系統參考《柔療髮浴_加班費計算表.xlsx》的制度設計，預設值如下，且每項都可以建立新版本調整。

### 4.1 共通參數

| 欄位 | 預設值 | 意義 |
| --- | ---: | --- |
| 月薪換算時薪除數 | 240 | 月薪制的加班時薪基數除數 |
| 時薪基數包含經常性提成與指定客獎金 | 包含 | 開啟時，月薪制基數把本期服務提成、商品提成和指定客獎金納入 |
| 一般月加班上限 | 46 小時 | 超過後顯示警示 |
| 勞資會議同意月上限 | 54 小時 | 超過後顯示較高層級警示 |
| 季度上限 | 138 小時 | 依季度累計並警示 |
| 平日單日延長工時 | 最多 4 小時 | 單筆超過即警示 |
| 單日總工時參考 | 最多 12 小時 | 排班與實際工時核對時使用 |

### 4.2 預設加班倍率

| 加班類型 | 聘僱類型 | 時段 | 倍率 |
| --- | --- | --- | ---: |
| 平日延長工時 | 全職／兼職 | 前 2 小時 | 1.34 |
| 平日延長工時 | 全職／兼職 | 第 3–4 小時 | 1.67 |
| 休息日出勤 | 全職／兼職 | 前 2 小時 | 1.34 |
| 休息日出勤 | 全職／兼職 | 第 3–8 小時 | 1.67 |
| 休息日出勤 | 全職／兼職 | 第 9–12 小時 | 2.67 |
| 國定／特別休假 | 全職 | 前 8 小時 | 1.00 額外給付 |
| 國定／特別休假 | 兼職 | 前 8 小時 | 2.00 |
| 國定／特別休假 | 全職／兼職 | 第 9–10 小時 | 1.34 |
| 國定／特別休假 | 全職／兼職 | 第 11–12 小時 | 1.67 |
| 例假日 | 全職 | 前 8 小時 | 1.00 額外給付 |
| 例假日 | 全職 | 第 9–12 小時 | 2.00 |
| 例假日 | 兼職 | 前 12 小時 | 2.00 |

倍率在「編輯加班倍率與階梯提成」中以百分比顯示：`134%`、`167%`、`267%`。分鐘區間使用分鐘，例如前 2 小時是 `0–120`。

### 4.3 建立新版本

1. 點「建立新版本」。
2. 填寫版本名稱和生效日。
3. 修改除數、是否含經常性提成、月／季度上限。
4. 儲存後，再編輯加班倍率與階梯提成。
5. 新版本生效後，舊版本保留供歷史結算查核。

## 五、按職稱設定階梯提成

| 指標 | 門檻單位 |
| --- | --- |
| 服務時數 | 小時 |
| 服務堂數 | 堂 |
| 服務業績 | NT$ 元 |
| 商品業績 | NT$ 元 |

先选择“职称 × 聘雇类型”，再编辑该组合的阶梯。每一阶可输入指标、算法、起点、终点和提成百分比；终点留空表示该起点以上。

- **累进区间**：只对落在该阶的服务时数、堂数或业绩计算该阶比例。进入高阶不会回头重算前段。
- **符合后整段套用**：达到门槛后，对整段对应业绩使用该比例。
- 没有阶梯时，系统使用“职称薪资设定”中的基本服务或商品提成。
- 服务时数在画面输入小时；服务／商品业绩在画面输入新台币元。数据库分别换算为分钟和分保存。

系统初始范本依据《技師薪資制度》：正职前 65 服务小时由底薪涵盖、第 66 小时起按 10 小时区间累进；兼职需先达到 40 出勤小时，再按服务时数阶梯；承揽默认前 100 堂 30%、之后区间 40%。所有门槛与比例都可以修改。

## 六、資料如何進入薪資

### 6.1 預約服務

必須同時為完成、已結帳且未退款。完成但未結帳會列為「待結帳」，不先計入業績、堂數薪酬和提成。

### 6.2 POS 服務

- POS 可直接選服務項目。
- 每個服務必須指定一位具備該服務能力的在職技師。
- 收款後服務業績、服務分鐘、完成堂數和服務提成歸該技師。

### 6.3 POS 商品

- 商品成交後自動扣庫存。
- 指定銷售人員時，商品業績和商品提成歸該人員。
- 成交時保存名稱、價格、成本和提成快照，日後修改商品不會改寫歷史。

### 6.4 實際技師

顧客預約時選的是預約技師；門店可以在後台指定實際服務技師。薪資、堂數、收入及評價都以實際技師為準，系統保留原技師、更換原因、操作人和提成變化紀錄。

## 七、加班與加扣項

“登录出勤”填写员工、日期、上／下班时间、休息分钟。核准出勤用于时薪基本工资与兼职提成资格。

「登錄加班」填員工、日期、加班類型、核准分鐘和原因。系統會依分鐘區間拆分倍率。已離職人員可做最後一期薪資調整，但不能再新增加班。

「新增加扣項」可選獎金、津貼、扣款、指定客獎金，金額單位一律為 `NT$ 元`。

## 八、試算、草稿與鎖定

每列顯示完成／已結帳／待結帳堂數、基本薪酬、服務及商品業績與提成、指定客獎金、加班費、其他加扣項、應發合計和警示。點「查看計算來源」可逐筆核對預約服務、POS 服務及商品訂單。

- 儲存草稿：可重新計算，適合尚在對帳時使用。
- 確認結算並鎖定：保存人員、職稱、聘僱類型、薪資規則、業績及結果快照。
- 重開結算：必須填寫原因，系統保留稽核紀錄。

## 十、每月結算檢查清單

- [ ] 每位在職人員都有正確職稱及聘僱類型。
- [ ] 基本薪酬、服務提成、商品提成及指定客獎金已核對。
- [ ] 時薪或有出勤門檻的人員已完成出勤登錄。
- [ ] 每个提成阶梯都选对职称与聘雇类型，单位为小时／堂／元。
- [ ] 完成療程已結帳，待結帳清單已處理。
- [ ] POS 服務都指定實際技師，商品需要提成者已指定銷售人員。
- [ ] 更換技師的預約已確認實際歸屬。
- [ ] 加班日期、類型、分鐘和原因已核對。
- [ ] 加班上限警示已處理。
- [ ] 獎金、津貼、扣款已輸入。
- [ ] 使用「查看計算來源」抽查服務和商品明細。
- [ ] 匯出 CSV 留存後，再確認結算並鎖定。
