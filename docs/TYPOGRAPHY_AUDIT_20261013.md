# 思源宋體與跨裝置排版檢查

核對日：2026-10-13。範圍：官網首頁、療程、商品、聯絡、預約／會員入口與後台共用字體。

## 找到的原因

舊 `rou-serif-tc-v1.woff2` 只包含 1,165 個靜態字碼，沒有完整涵蓋來自資料庫的療程內容。例如「苦、籽、森、呼、吸、禾、玉、烏、木、萃、湯、陽、鮮」不在舊子集中，瀏覽器會逐字改用裝置內建宋體，因此同一行的字形／粗細不一致。原本只驗證原始碼內文字的測試沒有抓到這類資料庫內容。

此外，90 分淡圈章與 120 分金章的寬度不同，讓相同標題的左緣偏移；價格、部分數字、表單及管理介面又使用不同字體。手機／平板班表的小字與跨午夜時間也有擠出日期格的情況。

## 已修正

- 採用 [Adobe 思源宋體](https://github.com/adobe-fonts/source-han-serif)台灣繁體可變字體，固定官方來源版本 2.003R。涵蓋該台灣版全部 **20,750 個字碼**，保留真實字重 **250–900**。
- 常用字及目前療程用字放在預載核心，其他字以不重疊的 `unicode-range` 按需下載；不因新商品／人名不在靜態原始碼就直接換成裝置字體。超出官方字庫支援的 Unicode 字元仍需使用備援字體。
- 依 OFL 保留原授權與來源說明，子集採不同內部／網頁字族名 `ROU Songti TC`；字形來源仍是思源宋體。字型檔、CSS、摘要雜湊與測試一併提交。
- 官網、會員、表單、管理介面與 iOS 共用入口使用同一字族；價格和一般數字也統一。LINE 等既有品牌圖形沿用其品牌字形。
- 療程名稱：桌面 18px／手機 17px、字重 600；副標 14px、字重 400；段落行高／字距統一。價格使用固定數字寬度功能與相同字體。
- 90／120 分章印保留各自淡圈／金章外觀，但使用相同版面尺寸、字號與字重。標題、副標及右側箭頭統一欄位，文字左緣一致。
- 提升後台常用說明、表格輔助文字、班表與出勤標籤的可讀性。手機表單維持至少 16px。班表時間使用 11px、局部日曆保留可左右捲動空間；平板上編輯區移到日曆下方，跨午夜文字不再擠出格子。
- 舊字體檔保留供舊快取頁相容；新頁面不再選用舊字族。

## 驗證

- 實際讀取生成 WOFF2 的 glyph map，和摘要中的字碼逐項比對。
- `test-public-fonts.mjs` 增加目前療程用字、全台灣字庫、分段不重疊、官方來源及核心預載檢查。
- 本地以公開目錄的唯讀回應檢查首頁、療程、商品、聯絡及會員入口：320、390、768、1440 寬度都使用相同字族，沒有整頁水平溢出。
- 章印／名稱／副標的實際樣式和文字起點逐項比對；相同視窗下所有療程名稱的左緣一致，字重／字號一致。
- 額外測試「祐、玥、芷、鬆、臺」等非核心用字，瀏覽器成功按需載入對應字體分段。
- 員工班表在 320、390、768、900、1024、1440 寬度核對時間文字寬度，全部在日期格內，整頁寬度不溢出。
- 隔離瀏覽器回歸 64 項通過，未向正式環境提交測試資料。網站與 iOS 網頁構建、原生同步通過。
- 以上為桌面瀏覽器不同視窗尺寸與本地字型驗證；不同裝置的字體平滑效果仍可能略有差異，不把這次檢查宣稱為每台手機的實機驗收。

## 檔案與維護

共用樣式：`src/typography.css`、`src/source-han-fonts.css`；資產與來源摘要：`public/fonts/`；產生器：`scripts/build-source-han-fonts.py`；驗證：`scripts/test-public-fonts.mjs`。

入口和既有樣式調整：`src/main.jsx`、`src/ios-main.jsx`、`src/OperationsShared.jsx`、`src/public-theme.css`、`src/App.jsx`、`src/Shop.jsx`、`src/services.css`、`index.html`、`mobile/index.html`。

本次為字體與排版修正，已核對操作手冊影響；預約、權限、薪資、付款和資料同步規則沿用原制度。維護時需保留字庫摘要驗證；不能只補某幾個靜態字就移除完整字庫分段，否則新目錄內容會再次混字。
