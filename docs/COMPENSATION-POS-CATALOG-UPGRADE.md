# ROU SPA 後台升級報告：薪資、POS、目錄與技師職稱

更新日期：2026-10-04

## 薪資資料模型

新增 `spa_compensation_profiles`，主鍵為按摩師職稱和聘僱類型。每個組合可設定：

- 月薪、時薪或每堂薪酬；
- 基本薪酬；
- 服務提成；
- 商品提成；
- 指定客每堂獎金；
- 啟用狀態。

保存規則時，系統同步既有相同條件的人員相容欄位，讓舊記錄、重派技師及歷史快照保持一致。新進人員選擇職稱和聘僱類型後自動取得對應制度。

## POS 與業績歸屬

新版 POS 接受服務及商品混合明細：

1. 商品檢查即時庫存，成交後原子扣庫存。
2. 服務要求指定具有該服務能力的有效技師。
3. 商品可指定銷售人員，依職稱規則計算商品提成。
4. 每筆明細保存名稱、單價、成本、人員和提成快照。
5. POS 服務納入服務堂數、分鐘、業績和薪資來源明細。
6. POS 收款納入經營報表收入與現金流水。

## 服務與商品刪除

刪除需要輸入 `DELETE`，並依歷史關聯自動選擇處理方式：

- 沒有預約、套票或訂單歷史：永久刪除。
- 已有歷史：轉為封存，保留帳務、薪資及稽核資料。

目錄預設不顯示封存項目，可用「顯示已封存」查看。批量上架、隱藏及封存仍保留。

## 單位修正

舊管理畫面曾直接顯示資料庫的最小貨幣單位，容易把 `110000` 認為是 NT$110,000。新版統一如下：

- 服務售價、會員價：NT$ 元；
- 商品售價、成本：NT$ 元；
- POS 折扣：NT$ 元；
- 薪資、獎金、津貼、扣款：NT$ 元；
- 提成、倍率：百分比；
- 療程、緩衝、加班區間：分鐘；
- 庫存：商品自訂單位。

前端把元換算為精確整數後再送到資料庫，讀取時再格式化為 NT$，避免浮點金額誤差。

## 經營報表

報表新增或修正：營業收入總額、預約服務收入、POS 收入、有效在職人員績效、人員職稱，以及預約和 POS 的服務／商品提成。

已離職人員仍可在適用期間的薪資頁完成結算，但不會混入目前在職人員經營績效。

## 官網與預約

公開技師資料新增 `title` 和 `title_en`。官網選擇技師、預約確認摘要、顧客查詢、顧客改期及完成療程評價都會顯示職稱。

## 安全與稽核

- 薪資制度修改需要 `payroll.manage`。
- 目錄刪除需要 `catalog.manage` 和明確文字確認。
- POS 需要 `pos.use`。
- 高影響操作寫入稽核記錄。
- 非店主員工權限仍限於營運首頁、預約與日程、評價、自己的薪資與績效。

## 驗證範圍

自動化測試覆蓋職稱薪資同步、前台職稱、服務與商品混合 POS、POS 服務薪資歸屬、有效人員報表、POS 收入、目錄刪除／封存，以及原有預約、會員、改期、評價、技師重派、排班、資料重設和權限流程。
