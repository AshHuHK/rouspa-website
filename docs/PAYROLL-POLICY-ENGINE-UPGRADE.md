# 柔療髮浴｜技師薪資制度重構報告

更新日期：2026-10-04

## 目标

将 POS、人员职称、出勤、服务完成记录、商品销售、指定客与薪资结算接成同一条数据链，并依据《技師薪資制度》建立可编辑、可版本化、可追溯的薪资规则。

## 已完成的修改

### 1. POS 商品销售与人员薪资

- POS 的每一个商品项目都可指定销售人员。
- 成交时保存销售人员、商品名称、数量、成交金额和当时职称商品提成快照。
- 商品销售业绩与商品提成直接进入该销售人员的当期薪资。
- 「职称薪资设定」可编辑每个“职称 × 聘雇类型”的商品销售提成百分比。
- 未指定销售人员的商品可以正常结账，但不会产生个人销售提成。

### 2. 指定客改为比例加成

- 指定客从“每堂固定金额”改为“该堂有效服务收入的百分比”。
- 计算只纳入实际完成、已结账且未退款的服务。
- 预约／POS 的实际服务人员必须与会员档案的指定技师一致，指定客加成才会进入该人员薪资。
- 一次性补差仍可使用薪资加扣项，系统保留审计记录。

### 3. 提成阶梯绑定职称

- 每一条阶梯都必须指定职称与聘雇类型。
- 全店共用、无法判断适用人员的阶梯已被移除；原有规则会先复制到现有职称组合，避免升级时丢失设定。
- 支持服务时数、服务堂数、服务业绩和商品业绩四种指标。
- 支持两种算法：累进区间、达到门槛后整段套用。
- 规则版本复制时，会同时复制职称阶梯和加班倍率；已锁定结算不受新版本影响。

### 4. 依据制度文档建立薪资模型

| 身份 | 初始规则 | 可编辑内容 |
| --- | --- | --- |
| 正职 | 月薪；前 65 服务小时由底薪涵盖；第 66 小时起按 10 小时区间累进 | 底薪、起算小时、每阶比例、指定客比例、商品比例 |
| 兼职 | 时薪；先达到 40 出勤小时；再按服务时数阶梯 | 时薪、出勤门槛、服务起算、每阶比例、指定客比例、商品比例 |
| 承揽 | 无固定底薪时可用服务堂数／业绩阶梯；初始为前 100 堂 30%、后续区间 40% | 计薪基准、门槛、区间、比例、指定客比例、商品比例 |

制度文档内兼职门槛出现“35／36”与“40／41”两组文字。系统初始值采用详细阶梯表的 40 小时门槛，并将该值做成可编辑字段，店主可按最终公告修改。

### 5. 出勤与服务小时分开

- 新增「登录出勤」，记录日期、上班时间、下班时间、休息分钟与备注。
- 出勤小时用于时薪基本工资和兼职提成资格。
- 服务小时来自完成、结账且未退款的预约或 POS 服务。
- 后台薪资表同时显示出勤小时、服务小时、最低出勤门槛和服务提成起算门槛。

### 6. 薪资透明度

- 薪资表新增指定客服务业绩、指定客比例、出勤资格与未达门槛警示。
- CSV／XLSX 增加出勤分钟、指定客服务业绩、指定客加成和职称阶梯。
- 结算快照保留规则版本、实际技师、职称、聘雇类型、阶梯范围和计算结果。
- 离职人员在仍有薪资资料的期间继续显示，历史记录不会因人员停用而消失。

## 单位

| 后台显示／输入 | 数据库保存 |
| --- | --- |
| 新台币元 | 分（`*_cents`） |
| 百分比 | 基点（`*_bps`，5% = 500） |
| 出勤／服务门槛小时 | 分钟 |
| 服务堂数 | 整数堂数 |

## 验证范围

- 薪资迁移可在完整数据库迁移链中执行。
- 商品销售指定人员后会产生商品提成快照。
- 指定客加成按实际服务收入比例计算。
- 提成阶梯全部绑定职称与聘雇类型。
- 累进阶梯按区间计算，不会因进入高阶回溯重算前段。
- 出勤记录可独立保存并进入薪资试算。
- 旧结算锁定、重开、离职人员范围、实际技师归属、退款排除和权限边界保持有效。

详细操作步骤见 [PAYROLL-SETUP-GUIDE.md](PAYROLL-SETUP-GUIDE.md)。
