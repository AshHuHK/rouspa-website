# 柔療髮浴｜薪資計算頁重構報告

更新日期：2026-10-04

## 重構目標

原薪資頁把試算、制度版本、出勤、加班、加扣項、抽成階梯、加班倍率和歷史結算放在同一畫面，資料欄位重複，日常核薪時需要橫向捲動，也容易把「每月結算」和「制度設定」混在一起。

本次參考《技師薪資制度》與「柔療髮浴技師薪資」HTML 的資訊層級，保留既有咖啡色後台風格，把功能整理成四個工作區。計算接口、資料表、正式制度版本及歷史快照沿用現有後端，因此不會重建或清空正式資料。

## 新版頁面結構

### 1. 薪資結算

- 顯示本期應發、可計抽服務營業額、抽成與指定客合計、待處理數。
- 主表只保留技師、出勤／服務、服務與業績、本薪、抽成、加班／加扣、應發及明細。
- 服務抽成、商品抽成和指定客獎金合併為主數字，細項仍顯示在下方。
- 完成但未結帳的服務不計薪，直接顯示待結堂數。
- 仍可切換制度版本試算、儲存草稿、確認鎖定，以及匯出 CSV／XLSX。
- 點選「明細」後可查核預約服務、POS 服務、商品銷售及實際技師歸屬。

### 2. 工時與加扣

- 集中顯示最近出勤、最近加班和本期加扣項。
- 登錄出勤、登錄加班、增加獎金／津貼／扣款分成三個清楚入口。
- 出勤時數只負責時薪和提成資格；服務時數仍由已完成且已結帳的服務自動累計。

### 3. 制度設定

- 頁首顯示目前啟用的制度版本、生效日和月薪換算除數。
- 正職、兼職、承攬各有一張制度摘要卡，可直接看起算點、比例範圍與階梯數。
- 職稱薪資、抽成階梯、加班倍率拆成三個編輯入口，不再放進同一個大型表單。
- 所有數值仍可編輯；建立新版本時保留舊結算快照。

### 4. 結算紀錄

- 集中顯示期間、狀態和鎖定時間。
- 已鎖定結算可填寫原因後重開，保留稽核紀錄。

## 預設制度

正式啟用版本沿用參考文件中的預設值：

| 類型 | 預設規則 |
| --- | --- |
| 正職 | 前 65 服務小時由底薪涵蓋，第 66 小時起每 10 小時一個累進區間，最高 35% |
| 兼職 | 出勤達 40 小時後取得抽成資格，服務時數按 5% 至 30% 累進 |
| 承攬 | 前 100 堂 30%，第 101 堂起 40% |
| 指定客 | 預設加成 5%，實際比例可依職稱 × 聘僱類型修改 |
| 加班 | 依聘僱類型、加班類型和分鐘區間設定倍率；月薪換算除數預設 240 |

職稱薪資頁可設定底薪／時薪／每堂薪酬、服務提成、商品提成、指定客比例、最低出勤和服務提成起算點。抽成表可設定時數、堂數或業績區間；加班表可設定每個分鐘區間的倍率。

## 計算與資料關係

- 預約服務必須完成、已結帳且未退款才計入薪資。
- 後台更換實際技師後，服務業績、完成堂數、抽成和顧客評價歸實際技師。
- POS 服務依結帳時指定的實際技師計入；POS 商品依指定銷售人員計入商品提成。
- 在職人員依人事資料中的職稱與聘僱類型套用制度。
- 已離職人員只在選定期間仍有待結薪資時顯示。
- 已鎖定的歷史結算保存當時的人員與制度快照，新設定不會改寫舊資料。

## 手機版調整

- 四個分頁可橫向滑動，不擠壓文字。
- KPI 在窄螢幕改為兩欄，最窄畫面改為單欄。
- 結算表在手機改為每位技師一張資訊卡，不再依賴寬表格橫向捲動。
- 操作按鈕自動換行；制度卡和編輯區在手機改為單欄。
