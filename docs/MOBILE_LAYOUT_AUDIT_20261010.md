# 手機排版與互動檢查

日期：2026-10-10

## 首頁文案

原本在超過 640px 的畫面會隱藏換行，段落限寬 400px，導致「心。」或「己。」單獨掉到下一行。改為按語意分行，各短句優先整段換行，保留原文與既有字體、色系。

目前顯示：

> 取東方養護之意，循舒緩調理之法  
> 由頭開始，漸入身心。

> 五感療癒

> 頭皮養護、頭肩頸按摩與髮浴，  
> 在嘉義，留一段時間給自己。

檢查 320、360、375、390、414、640、641、768、1024、1440px，兩段文案均維持上述分行，沒有單字孤行及橫向溢出；320px 將文案字級放大一倍時，也能按完整短句換行。中英文手機文案另檢查 320／390／768px。

## 手機預約互動

- 在正式網站重現：長月曆／時段頁按下一步後，確認摘要的標題留在視窗上方（y=-214px），使用者直接看到表單中段。
- 步驟切換及成功回執對齊新標題，首次進站及普通資料更新不強制捲動；以即時對齊避免額外捲動動畫。
- 指定技師月曆分行顯示起迄時間，選中日期顯示完整上班時段，跨日標示「翌日」。
- 姓名、手機、備註補上固定欄位標籤，選擇狀態及日期提供完整輔助閱讀名稱。

## 手機入口

聯絡頁 LINE 諮詢、商品頁返回首頁品牌、服務頁品牌／頁尾連結，以及首頁會員中心入口擴大至至少 44px 的可點高度。原本 LINE 諮詢約 33.5px、商品品牌約 24.5px、服務品牌約 27.75px、首頁會員入口約 19px。

## 手機後台

- 700px 以下，文字輸入、選單及文字區調整為 16px，避免小字欄位造成手機聚焦縮放；不放大日期格及一般按鈕。
- 有問管家／待辦浮動入口的頁面預留頁尾安全空間，末尾操作可捲到浮標上方；登入頁不增加這段留白。
- 彈窗採動態視窗高度上限 `90dvh` 並限制捲動傳遞；窄螢幕可在彈窗內捲動。
- 本地合成資料檢查：營運月曆切月／選日、床位與待辦、商品編輯彈窗、POS 尾部、員工出勤按鈕狀態及補卡彈窗。沒有送出正式打卡、定位、收款或人事修改。
- 營運月曆在 320／375／390／768px 沒有整頁橫向溢出。商品彈窗在 320／375／390px 的實測寬度為 296／351／366px，內容可捲動；375×360px 下商品彈窗、待辦與問管家仍在視窗內。

## 手機排班選日期

原本日期格只處理 `pointerdown` 與滑鼠移入；觸控捕捉使手指移動不會觸發其他格子的連選。改用獨立 `RosterDatePicker`：

- 單日點選在完整點擊後生效，手指上下滑動保留正常捲動。
- 「選擇連續日期」點起日與迄日；可反向選、清除起日或退出模式。
- 滑鼠拖選及鍵盤 Enter／空白鍵保留。
- 切換月份／人員重設未完成的起日；過去日期不能選。切換人員載入該人今日的班表，切換月份清除日期選擇，避免套用上個月的日期。
- 所有選擇只是本地草稿；「套用到所選日期」的正式保存、權限、日期與預約衝突驗證沿用原規則。

合成資料互動驗證包含 12–15 日滑鼠拖選、18→14 日反向範圍、單日點選、鍵盤、過去日期、換月、清除／退出。只選日期沒有發出保存請求。

## 驗證方式與範圍

以 Tabbit 實際瀏覽器調整視窗寬度驗證。預約在 320／375／390px 檢查指定技師、挑時間、不指定三條路徑；下一步／上一步及成功回執標題位於導覽下方 16px（測得 y=85–89px），不被頂部遮擋。首次載入維持原位置，模擬普通資料更新後捲動位置及正在填寫的手機欄焦點均保持。返回後姓名、手機仍保留；模擬逾時保留姓名、手機與備註，按鈕恢復可用，重試成功且沿用原操作編號。

公開導覽、療程展開、商品分類、聯絡頁、服務頁以及會員／查詢入口另做手機檢查，空白必填欄仍正常阻擋送出，沒有因本輪調整增加整頁橫向溢出。首頁圖片的 React 18 屬性改為小寫 `fetchpriority`，保留高優先載入並移除未知屬性警告。

正式網站只查看公開資訊及進入提交前的預約步驟，沒有新增正式預約、交易或人員；成功／失敗流程及後台元件用本地合成資料檢查。這是瀏覽器窄視窗驗收，不代表每款手機、所有 Safari／Android 系統版本的實機測試。

本輪 UI 操作要點同步到 [營運手冊](../ROU_SPA_OPERATING_MANUAL.md) 第 3、7.2 節，部署後供問管家閱讀。

完整 `npm test`、`npm run build`、`git diff --check` 均通過；包含新的 13 項預約日期／班時檢查、靜態中文字形覆蓋，以及既有預約、排班、權限、出勤、薪資、POS 與即時更新檢查。排班選擇器另經獨立程式審查，切換人員及月份的草稿狀態用實際 SmartRoster 合成資料驗收。
